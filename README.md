# AcxiomCRM – Customer Relationship Management System

## Technologies Used
- C#
- ASP.NET Core MVC
- Entity Framework Core
- SQLite
- ASP.NET Core Identity
- Bootstrap

## How to Run

1. Clone the repository:
   `git clone https://github.com/renukamarri4/AcxiomCRM.git`

2. Open the project folder:
   `cd AcxiomCRM`

3. Restore dependencies:
   `dotnet restore`

4. Apply database migrations:
   `dotnet ef database update`

5. Run the application:
   `dotnet run`

6. Open the localhost URL displayed in the terminal.

## Implemented Features
- User registration and login
- Customer management (CRUD)
- Lead management (CRUD)
- Opportunity management (CRUD)
- Follow-up management (CRUD implementation)
- Dashboard with database record counts

## Database
SQLite with Entity Framework Core migrations.
